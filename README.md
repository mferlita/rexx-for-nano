# rexx-for-nano
Better syntax highlighting support for [NetRexx](https://www.netrexx.org/index.nsp) and [ooRexx](https://sourceforge.net/projects/oorexx/) 
for the [GNU nano](https://www.nano-editor.org/) text editor.

To do:

2. Support for multiple popular themes like Catppuccin and Dracula, as well as a default. 
3. Include installation instructions

NetRexx is case-insensitive, but regex syntax highlighting can confuse words
important to Rexx. To avoid confusion, a certain style is recommended. Keywords
and related syntax are capitalized. Variables should use camelCase or 
snake_case. Class and method names should use PascalCase and camelCase 
respectively.
