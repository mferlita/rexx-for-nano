# rexx-for-nano
Better syntax highlighting support for [NetRexx](https://www.netrexx.org/index.nsp) and [ooRexx](https://sourceforge.net/projects/oorexx/) 
for the [GNU nano](https://www.nano-editor.org/) text editor.
